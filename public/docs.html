API Reference

Base URL: https://zapi.xoui.dpdns.org/v1 · OpenAI-compatible · JSON only · Content-Type: application/json

Authentication

Send your key in the standard header, or use ?key= for quick tests:

Authorization: Bearer <your-zapi-key>
  or GET /v1/models?key=<your-zapi-key>

Free tier works immediately — grab a key from the homepage. No signup.

Endpoints

POST /v1/chat/completions

Identical to OpenAI Chat Completions.

{
  "model": "glm-5.2",
  "messages": [{"role": "user", "content": "Hello!"}],
  "max_tokens": 200
}

Models: glm-5.2, kimi-k2.7, deepseek-v4.1-flash, hy4-preview (subject to upstream availability; unknown models fall back to the pool default).

GET /v1/models

List available models.

GET /health

Service health + free-tier daily allowance.

Rate limits

TierDaily requestsBurst
Free50~10 req/min
Pro5,000priority routing
Scale25,000dedicated pool

Exceeded → 429 with a clear error body. Daily limit resets at UTC midnight.

Errors

Standard OpenAI error shape: {"error": {"message": "...", "type": "..."}}

✓ Multi-pool automatic failover — you get a response even when one upstream is down.

SDK examples

Python (openai)

from openai import OpenAI
client = OpenAI(base_url="https://zapi.xoui.dpdns.org/v1",
                api_key="your-zapi-key")
r = client.chat.completions.create(model="glm-5.2",
      messages=[{"role":"user","content":"hi"}])
print(r.choices[0].message.content)

curl

curl https://zapi.xoui.dpdns.org/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your-zapi-key" \
  -d '{"model":"glm-5.2","messages":[{"role":"user","content":"hi"}]}'
